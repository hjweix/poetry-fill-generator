## 诗词填空生成器 v2 优化（晚）

1. **修复 Word 导出失败**：docx v9 中 `Packer.toBlob()` 是正确的浏览器 API，旧代码用了 `toBuffer + Uint8Array` 导致 Blob 类型错误。改为 `Packer.toBlob()` 为主，兜底 `toBuffer → ArrayBuffer → Blob`；同时优化 Word 内填空为真正下划线（`UnderlineType.SINGLE`），按批量/单首模式分组输出。
2. **预览改为试卷风格**：重写 `QuestionPreview.tsx` 和相关 CSS，去掉所有卡片/渐变/装饰，改为：居中标题"诗词填空题"、双横线分隔符、阿拉伯数字编号"1."格式、填空处用真下划线 `border-bottom` 显示、参考答案小字灰色显示。打印 CSS 也同步更新适配新类名。
