## 产品概述

将「整句填空」从难度选项中提取为全局挖空程度设置，支持1-2个词、3-4个词、整句三种级别，同时应用到智能拆题和手动拆分两种模式。

## 核心功能

### 1. 全局挖空模式

- 新增独立的挖空程度选择器，替换原有DifficultySelector
- 支持三种级别：1-2个词（简单）、3-4个词（中等）、整句（困难）
- 该设置为全局，对智能拆题和手动拆分均生效

### 2. 智能拆题适配

- 挖空模式直接控制每句的挖空字数
- 1-2个词：每句挖空1-2字
- 3-4个词：每句挖空3-4字
- 整句：挖空逗号间整段

### 3. 手动拆分适配

- 保留拖选诗句添加选题功能
- 题目卡片中逐字选词挖空
- 当设置为整句模式时，点击句子卡片直接整句挖空，无需逐字点击

## 数据结构

```typescript
// 新增挖空模式类型
export type BlankMode = 'few' | 'some' | 'whole';

// 映射关系
// 'few'   → 1-2个词（原easy）
// 'some'  → 3-4个词（原medium/hard合并）
// 'whole'  → 整句（原sentence）
```

## 实现思路

### 1. 类型定义调整

- 新增 `BlankMode` 类型：'few' | 'some' | 'whole'
- `DifficultyLevel` 类型保留用于向后兼容（内部映射）
- 新增 `blankModeToDifficulty` 映射函数

### 2. 组件重构

#### BlankModeSelector（新建）

- 独立的挖空程度选择器组件
- 三个选项：1-2个词、3-4个词、整句
- 使用紧凑的chips布局

#### SmartSplitConfig（修改）

- 移除 `DifficultySelector` 组件
- 改用 `BlankModeSelector`
- 调整props类型

#### SplitModePanel（修改）

- 移除 `difficulty` 相关props
- 新增 `blankMode` props

#### TextSelectionEditor（修改）

- 新增 `blankMode` prop
- 整句模式时：点击句子卡片整行文字直接设为选中
- 逐字模式时：保持现有逐字点击逻辑

### 3. 状态管理更新

#### App.tsx

- 将 `difficulty: DifficultyLevel` 改为 `blankMode: BlankMode`
- `splitModePanel` 和相关组件传递 `blankMode`
- 生成题目时转换 `BlankMode` → `DifficultyLevel`

### 4. 工具函数更新

#### fillGenerator.ts

- 新增 `blankModeToDifficulty` 映射函数

```typescript
function blankModeToDifficulty(mode: BlankMode): DifficultyLevel {
  switch (mode) {
    case 'few': return 'easy';
    case 'some': return 'hard'; // 使用hard获得3-4字
    case 'whole': return 'sentence';
  }
}
```

### 5. 数据流设计

```
用户选择BlankMode 
    ↓
App.tsx保存状态
    ↓
传递到SplitModePanel
    ├─ 智能拆题 → SmartSplitConfig → BlankModeSelector
    └─ 手动拆分 → TextSelectionEditor
    ↓
生成题目时 blankModeToDifficulty(blankMode)
    ↓
generateFillBlankQuestions(difficulty)
```

## 实现细节

### TextSelectionEditor 整句模式交互

```typescript
// 当 blankMode === 'whole' 时
const handleLineClick = (groupId: number, lineIdx: number) => {
  if (blankMode === 'whole') {
    // 自动选中该行所有非保护字符
    const updated = groups.map(g => {
      if (g.id !== groupId) return g;
      return {
        ...g,
        interactiveLines: g.interactiveLines.map((ld, idx) => {
          if (idx !== lineIdx) return ld;
          return {
            ...ld,
            blanks: ld.blanks.map(b => ({
              ...b,
              isSelected: b.importance > 0 // 选中所有可挖空字符
            }))
          };
        })
      };
    });
    onChange(updated);
  }
  // 否则保持现有逐字点击逻辑
};
```
