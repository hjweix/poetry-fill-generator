## 产品概述

增强手动拆分模式，让用户能够直接选中诗词中的任意文字（而不仅仅是勾选整行诗句）来创建填空题。用户通过鼠标拖选文字范围，选中后出现浮动操作按钮，点击即可将所选文字单独提取为一道题目。

## 核心功能

### 1. 精确文字选择

- 在诗句展示区域中，用户可以像在普通文档中一样用鼠标拖选任意文字范围
- 支持跨行选择（连续多行的部分文字）
- 选择范围实时高亮显示

### 2. 浮动操作按钮

- 用户选择文字后，在选区附近出现浮动按钮"设为挖空"
- 按钮跟随选区位置，点击后创建新题目
- 支持撤销选择（按ESC或点击其他区域）

### 3. 题目创建流程

- 所选文字被提取为独立的题目
- 自动填充诗词标题和作者信息
- 所选文字在原诗中用删除线或特殊样式标记，避免重复选择
- 支持连续选择创建多个题目

### 4. 兼容现有系统

- 保持现有ManualGroup数据结构
- 保持题目卡片逐字选词功能
- 保持预览、导出等外围功能不变

## 技术栈

沿用现有项目栈：React 18 + TypeScript + Vite + 自定义CSS。

## 实现思路

### 选区方案选择

采用**浏览器原生Selection API**而非自定义拖拽实现，理由：

1. **用户友好**：与普通网页文字选择行为完全一致
2. **跨浏览器兼容**：Selection API是所有现代浏览器标准
3. **实现简单**：无需处理复杂的mousedown/mousemove/mouseup事件链
4. **性能优秀**：浏览器原生事件处理，无额外DOM监听负担

### 核心架构调整

#### 1. 文本选择监听器

```typescript
// 新增选区状态类型
interface TextSelection {
  startLineIndex: number;
  startCharIndex: number; 
  endLineIndex: number;
  endCharIndex: number;
  selectedText: string;
}

// 监听selectionchange事件
useEffect(() => {
  const handleSelectionChange = () => {
    const selection = window.getSelection();
    if (selection && selection.rangeCount > 0) {
      // 解析选区范围，判断是否在诗句区域内
      // 计算行索引和字符索引
      // 设置浮动按钮位置
    }
  };
  
  document.addEventListener('selectionchange', handleSelectionChange);
  return () => document.removeEventListener('selectionchange', handleSelectionChange);
}, []);
```

#### 2. 诗句渲染方式调整

当前渲染方式：

```
// 现在：每个字符作为单独的<span>按钮
<span className="mse-char mse-char--selectable">字</span>

// 改为：完整诗句作为可选择文本块
<div className="mse-line-text selectable-text">床前明月光</div>
```

#### 3. 浮动按钮定位

```css
.selection-floating-btn {
  position: absolute;
  top: calc(选区top - 40px);
  left: 选区中心点x;
  transform: translateX(-50%);
  z-index: 1000;
  animation: fadeIn 0.2s ease;
}
```

### 数据处理流程

1. **选区解析** → 将Selection Range转换为`{行索引, 字符索引}`坐标
2. **文本提取** → 从原始诗句中提取选中的文字
3. **题目创建** → 将提取文字包装为新的`ManualGroup`
4. **样式更新** → 在原诗中标记已选择部分，防止重复选择

### 性能考虑

- 使用`debounce`或`requestAnimationFrame`优化selectionchange事件
- 使用`useMemo`缓存文本节点引用
- 避免频繁的DOM查询和样式计算
