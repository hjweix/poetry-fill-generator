# 诗词填空生成器

一个简单易用的Web版诗词填空生成器，支持用户输入诗词文本，选择填空难易程度，自动生成填空考试题并导出为Word文档。

## 功能特性

- 📝 **诗词输入**：支持输入诗词标题、作者和内容
- 🎯 **难度选择**：提供简单、中等、困难三个难度级别
- ✨ **智能填空**：根据难度自动生成不同数量的填空
- 📄 **Docx导出**：一键导出为Word文档格式
- 📋 **文本复制**：支持复制纯文本格式的填空题
- 🎨 **美观界面**：现代化的响应式设计，支持移动端

## 技术栈

- React 18 + TypeScript
- Vite 构建工具
- docx 库用于文档生成
- file-saver 用于文件下载
- CSS3 响应式设计

## 使用方法

1. **输入诗词信息**：
   - 填写诗词标题和作者信息
   - 在文本框中输入诗词内容，每行一句

2. **选择难度级别**：
   - 简单：每句填空1-2个字
   - 中等：每句填空2-3个字
   - 困难：每句填空3-4个字

3. **生成填空题**：
   - 点击"生成填空题"按钮
   - 在右侧预览生成的填空题

4. **导出或复制**：
   - 点击"复制文本"复制纯文本格式
   - 点击"导出Docx"下载Word文档

## 填空算法说明

- **智能保护**：自动保护标点符号和虚词不被填空
- **难度分级**：
  - 简单：约15%字符填空
  - 中等：约25%字符填空
  - 困难：约35%字符填空
- **随机分布**：填空位置随机分布，确保每次生成略有不同
